**Project Setup Instructions**

**Frontend (Angular)**
1. Clone the repository.
2. Navigate to the `ecom-web-app` folder.
3. Install the dependencies:
   `npm install`
4. Ensure Angular CLI is installed.
5. Start the application:
   `ng serve -o`

**Backend (Node.js)**
1. Navigate to the `ecommerce-backend` folder.
2. Install the dependencies:
   `npm install`
3. Configure the database connection in the provided `.env` file.
4. I have included the database migration script. Run the migration if required using the configured migration command.
5. Start the backend:
   `npm run start`

The frontend and backend are ready to be configured and run locally. Please ensure MySQL is running and the database credentials in `.env` are correct before starting the backend.
